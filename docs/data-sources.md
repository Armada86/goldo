# Data sources

Reference for every external data source this project reads from -- what it's used for in production
code, what it's actually capable of, and the real limitations/challenges run into while using it (both
in production and during ad hoc analysis sessions, e.g. the frequency-test/companion-swing studies run
from Claude Code). Three sources (yfinance, Twelve Data, FRED) are wired into production code today;
FMP was evaluated in a session as a possible additional/replacement source and is not yet used by any
project code.

| Source | Used for (production) | Capabilities | Challenges / limitations encountered |
|---|---|---|---|
| **yfinance** | `dxy`, `us10y`, `gld`, `iau`, `gldm`, `gdx`, `gdxj`, `ring` live prices (`config.INDICATORS`, `data_fetcher._fetch_yfinance_price`); `GC=F` gold-futures daily closes for `rules.check_sma_crossover`; `frequency_test.py`'s `dxy`/`us10y` backtest data specifically (5-min bars, ~30-day rolling window, `FREQUENCY_TEST_LOOKBACK_DAYS`) -- the six gold ETFs' backtest data moved to Twelve Data (see below). | Free, no API key, no request-count billing. Covers equities/ETFs, major indices (`DX-Y.NYB` for the Dollar Index), Treasury yields (`^TNX`), and futures (`GC=F`) all from one library. Intraday bars down to 1-minute; daily history goes back years. | **1-minute bars are capped at ~7-8 days** by Yahoo itself, regardless of how the request is made -- a 30-day `period="30d", interval="1m"` request returns 0 rows outright rather than truncating silently; confirmed this cap applies uniformly (tested on GLD). This is exactly why `dxy`/`us10y` are the two indicators frequency_test.py still can't get 1-minute data for over a 30-day window -- yfinance is the only source with a genuine Dollar Index/intraday Treasury-yield instrument at all, but not at 1-minute resolution over that long a lookback. **5-minute bars are capped at 60 days.** Occasional throttling observed on rapid repeated calls during ad hoc analysis (not seen with yfinance's normal 5-min-interval production polling, only during bursts of many back-to-back historical pulls). |
| **Twelve Data** | `gold`'s live spot price (`fetch_gold_spot_price()`, `GOLD_SPOT_SYMBOL = "XAU/USD"`); gold's 15-min RSI candles (`fetch_gold_candles()`, used every poll by `rules.check_rsi_alerts`); `frequency_test.py`'s backtest data for gold spot and all six gold ETFs (GLD/IAU/GLDM/GDX/GDXJ/RING), true 1-minute bars paginated back `FREQUENCY_TEST_LOOKBACK_DAYS` (30) days. | Real spot-gold pricing (yfinance has no true spot symbol anymore -- see `CLAUDE.md`), true 1-minute bars for forex/commodities/most equities, full OHLC per bar. `time_series` supports `start_date`/`end_date` pagination, so a 30-day 1-minute history is obtainable in ~2-9 paginated calls per symbol depending on how many hours/day the instrument trades. | **Free-tier rate limit is 8 credits/minute** -- paginating 30 days of 1-min XAU/USD data (needing ~9 calls) hit a 429 mid-pull and required a ~65s cool-down plus 8-9s pacing between subsequent calls; `frequency_test.py` paces every call by 9s for exactly this reason. **Default response timestamps are not UTC** -- confirmed empirically (a batch with no `timezone` param came back ~10 hours ahead of real UTC); every pull passes `timezone=UTC` explicitly to avoid silently misaligning against yfinance data when cross-referencing timestamps. **No real Dollar Index or Treasury-yield symbol at accessible tiers**: `DXY` is rejected outright as an invalid symbol; `USDX` and `DX` *do* return prices, but `symbol_search` confirms they resolve to unrelated tickers (SGI Enhanced Core ETF and Dynex Capital Inc, a REIT) -- a real trap, since the prices looked plausible enough at a glance to use by mistake. `TNX` (real 10-year yield) exists but is gated behind a higher ("Grow"/"Venture") plan than currently subscribed -- this is why `dxy`/`us10y` stay on yfinance in production. |
| **FRED** | `inflation` (T10YIE, daily), `financial_stress` (STLFSI4, weekly), plus the other `config.FRED_SERIES` scheduled-release indicators (`adp_employment`, `nonfarm_payrolls`, etc.). | Official, authoritative US government/Fed economic data. Free, reliable, no rate-limit issues encountered. | Update frequency is **daily/weekly at best**, never intraday -- by design, not a limitation to work around (this is why `financial_stress` uses `check_value_change_alerts` rather than an intrahour mechanism, and why `inflation`/FRED series are excluded from `INTRAHOUR_SWING_ALERT_THRESHOLD`). No historical intraday backtest is possible against FRED series for this reason. |
| **FMP** (Financial Modeling Prep) -- *evaluated only, not wired into any project code yet* | Not used in production. Explored in a session as an alternative/supplementary source for the frequency-test-style analysis (companion-swing and co-flagging studies). | Under the subscribed plan: clean 5-minute OHLC bars for equity ETFs (GLD/IAU/GLDM/GDX/GDXJ/RING all confirmed) with **no rate-limit friction observed** across 10+ rapid back-to-back calls -- notably smoother than Twelve Data's free-tier pacing requirements. Also has a genuinely useful **economic calendar** (`/stable/economic-calendar`) with real ADP/NFP release dates *and* times (confirmed: ADP consistently 12:15 UTC / 8:15am ET, NFP 12:30 UTC / 8:30am ET, matching `CLAUDE.md`'s documented schedule) plus `previous`/`estimate`/`actual` figures -- the `estimate` (consensus) field is something the project currently has no automated source for at all (`nfp_reports`/`adp_reports` rows are filled in by hand during one-off research). | Most `/api/v3/` and `/api/v4/` endpoints are **deprecated/legacy** and return 403 for any subscription started after August 31, 2025 -- only the newer `/stable/` endpoint family works. **1-minute intraday data is restricted above the current plan tier** for every symbol tested (XAUUSD and all 6 gold ETFs all returned 402 "Restricted Endpoint"), so only 5-minute resolution is actually usable today. **No Dollar Index instrument at all** (`DXY` returns an empty list, not an error). **No intraday Treasury yield** -- `/stable/treasury-rates` only returns one value per day (a `year10` field), no intraday resolution whatsoever. Would need proxy instruments (UUP for DXY, IEF/TLT for US10Y -- inversely related to yield) to cover those two gaps, which was evaluated but not adopted (see below). |

## Net effect on frequency_test.py

Given the above, the source split adopted in production `frequency_test.py` is: **gold spot + all 6
gold ETFs from Twelve Data (genuine 1-minute bars, 30-day pagination)**, **DXY and US10Y from yfinance
(5-minute bars, the best available for those two anywhere)**. FMP was evaluated and found to have no
accessible advantage for this study (worse gold/ETF resolution than Twelve Data under the current plan,
and no usable DXY/US10Y path at all) -- its practical value to this project right now is the
economic-calendar endpoint, which nothing in the codebase currently uses.

No proxy instruments (UUP for DXY, IEF/TLT for US10Y) were adopted -- by explicit choice, those two
stay on yfinance's real (if coarser) data rather than substituting a correlated-but-different
instrument.
